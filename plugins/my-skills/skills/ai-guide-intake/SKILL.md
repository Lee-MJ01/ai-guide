# ai-guide-intake — 자료를 가이드 저장소에 넣기

사용자가 준 자료를 분석해 **GitHub `Lee-MJ01/ai-guide`(글 원본)**와 **Google Drive `내 드라이브/AI_공통_작업_가이드/`(큰 파일·비밀·개인 자료, 이하 `[Drive]`)**에 반영한다. 사용자는 확인 없이 맡기는 편이므로, 아래 규칙을 지키는 한 묻지 말고 끝까지 진행한다.

## 1. 환경 확인 (조용히, 한 번)

| 필요한 것 | 찾는 곳 | 없으면 |
| --- | --- | --- |
| git + GitHub 쓰기 | Claude Code 셸, 클라우드 세션(저장소를 push 권한으로 붙이기), PC 셸(device_bash) | 4장 "쓰기 불가" |
| Drive 쓰기 (큰 파일이 있을 때만) | PC 폴더 `G:\내 드라이브\AI_공통_작업_가이드`(연결 요청 가능) 또는 Google Drive 커넥터 | 큰 파일은 사용자에게 돌려주고 업로드 위치만 알려줌 |
| 영상 분석 | Claude 데스크톱 앱 내장 브라우저 | 캡션·설명만으로 정리하고 "음성·화면 미분석" 표시 |

## 2. 저장소 준비 → 규칙 읽기

1. 클론이 있으면 `git -C <클론> pull --ff-only`, 없으면 `git clone --depth 1 https://github.com/Lee-MJ01/ai-guide.git` (Google Drive 같은 동기화 폴더 안에는 받지 않음).
2. 읽는 파일은 이 3개뿐: `index.md`, `00_공통기준/저장소_운영_규칙.md`, `00_공통기준/새_자료_정리_규칙.md`. 이후 고를 폴더의 `index.md`만 추가로 연다.

## 3. 자료 분석 (종류별)

| 자료 | 방법 |
| --- | --- |
| 유튜브·인스타 릴스·게시물 | `youtube-watch` 스킬 analyze 모드. "스킬로 만들어"가 있으면 learn 모드 |
| PDF | 원본은 `[Drive]/<폴더>/`에 두고 `pdf-drive-analyzer`로 캐시 → 요약 md |
| 웹 글·노션·GitHub 저장소 | WebFetch → 안 되면 내장 브라우저. 남의 노션은 Notion 커넥터로 안 열림 |
| 붙여넣은 글·파일 | 그대로 분석 |
| 열 수 없는 링크 | 정리하지 말고 `_정리대기.md` 1장 표에 사유·해결 방법과 함께 추가 |

- 원문을 통째로 옮기지 않는다. 내 말로 요약하고 링크를 남긴다. 인용은 꼭 필요할 때 한 군데, 15단어 미만.
- 주장(조회수·성능 수치 등)은 원본으로 교차 확인하고 "주장과 확인할 점"에 분리.
- 스킬·플러그인·MCP 소개면 설치 명령을 공식 저장소 README로 확인한다.

## 4. 반영

1. **중복 확인:** `git grep -n "<URL 또는 shortcode·영상 ID·저장소명>"`. 있으면 새로 만들지 말고 그 문서를 보강한다.
2. **위치:** 루트 `index.md` 폴더 목차로 고른다. 스킬·플러그인·MCP 소개는 `06_스킬_플러그인/`(MCP·LLM 도구는 `05_LLM다루기/`), 디자인은 `07_디자인/`.
3. **파일:** `새_자료_정리_규칙.md` 형식. 첫머리 `> 요약: … | 언제: … | 키워드: … | 관련 스킬: … | 출처: … | 갱신: YYYY-MM-DD` 필수. 영상·게시물은 정보 → 핵심 요약 → 바로 써먹을 것 → 주장과 확인할 점 → 분석 한계 → 출처.
4. **인덱스:** 같은 커밋에서 폴더 `index.md`에 한 줄. 새 폴더면 루트 `index.md` 목차·빠른 길도. 설치 가능한 스킬·플러그인이면 `06_스킬_플러그인/스킬_플러그인_레지스트리.md`(설치 전이면 "검토 대기")에도.
5. **큰 파일:** `[Drive]/<같은 폴더>/`에 올리고 md·index에는 `[Drive]/경로`만 적는다. 커밋하지 않는다.
6. **공개 저장소 점검:** 비밀·개인 경력·연락처·이력서 원본이 diff에 없는지 `git diff --cached`로 확인. 개인 정보는 `[Drive]/_개인/`에만.
7. **커밋·push:** `add: <무엇> (<PC 또는 환경>)` (기존 문서 보강이면 `update:`). 끝에 바로 `git push`. 거절되면 `git pull --rebase` 후 재시도. force push·reset 금지.

**쓰기 불가 환경(git이 없는 일반 채팅):** 완성된 md 전체와 넣을 경로·인덱스 줄을 보여 주고, "git이 되는 세션에서 '방금 정리한 거 저장소에 반영해줘'라고 하면 올린다"고 알린다. Drive에 md를 대신 쓰지 않는다.

## 5. 보고 (짧게)

- 만든·고친 파일 경로와 GitHub 링크(`https://github.com/Lee-MJ01/ai-guide/blob/master/<경로>`) 한두 줄
- Drive에 올린 파일, `_정리대기.md`로 보낸 항목, 확인 못 한 부분
- 설치할 만한 스킬·플러그인이면 설치 명령 한 줄 제안 (설치는 승인 후)
