# PDF Drive Analyzer

원칙: **변환은 한 번, 읽기는 필요한 만큼, 이미지는 의심 페이지만.** 변환은 정보 추출일 뿐 정확성 검증이 아니다.

## 0. 경로 확정 (매 세션 첫 단계)
Drive 루트 `DRIVE`를 찾는다. 우선순위:
1. 환경변수 `AI_GUIDE_DIR`가 있으면 그 값
2. Windows: `G:/내 드라이브/AI_공통_작업_가이드` (G: 아니면 다른 드라이브 문자 `*:/내 드라이브` 또는 `My Drive` 탐색)
3. macOS: `~/Library/CloudStorage/GoogleDrive-*/내 드라이브/AI_공통_작업_가이드` (또는 `My Drive`)

고정 위치:
- 스크립트: `DRIVE/tools/pdf_ingest.py`
- 캐시: `DRIVE/_pdf_cache/<sha16>/` (스크립트가 자동 결정), 목록 `DRIVE/_pdf_cache/catalog.tsv`
- 분석 결과: 사용자가 정하지 않으면 원본 PDF 옆 `<이름>.analysis.md`

스크립트가 없으면 Google Drive 커넥터로 `tools/pdf_ingest.py`를 찾아 받아 저장한다. 커넥터도 없으면 사용자에게 알린다.
의존성: `python -m pip install pymupdf` (없을 때만, 가능하면 venv). Drive 동기화 폴더 안에 venv를 만들지 않는다.

## 1. 변환 (캐시 우선)
```
python "DRIVE/tools/pdf_ingest.py" "<pdf 경로>"
```
- `CACHE HIT`면 재변환하지 않는다. 다른 컴퓨터에서 만든 캐시도 동일 해시면 그대로 사용.
- `--force`는 사용자가 재변환을 원하거나 스크립트 버전이 바뀌었을 때만.
- 여러 PDF는 파일마다 실행하고, 하나가 실패해도 나머지를 계속한다.
- 원본 PDF는 절대 수정·이동하지 않는다.

## 2. 읽기 순서 (토큰 절약 핵심)
1. **index.md만 먼저 읽는다** — 쪽수, 북마크 목차, 페이지별 글자 수·플래그·첫 줄. 이것으로 관련 페이지 후보를 고른다.
2. **검색**: 질문 키워드로 `full.md`를 grep(`<!-- p.N -->` 마커로 페이지 역추적). 동의어·영문 표기도 함께.
3. **필요한 페이지만** `pages/pNNN.md`로 읽는다. 전체 요약 요청이 아니면 full.md 통째 읽기 금지.
4. 전체 요약이 필요하면: 50쪽 이하는 full.md, 그 이상은 목차 단위 묶음으로 나눠 읽고 장별 요약을 `<sha16>/notes.md`에 누적 저장(다음 세션 재사용).

## 3. 시각 확인 (선택적)
index.md의 플래그가 판단 기준이다.
| 플래그 | 조치 |
|---|---|
| `SCAN?` / `EMPTY` | 내용 없음으로 판단하지 말 것. `--render N`으로 PNG를 만들어 직접 보고 판독. 판독 결과는 `pages/pNNN.ocr.md`로 저장해 재사용 |
| `TABLE×n` | 추출 표와 렌더 이미지를 대조. 숫자·열 관계·단위가 답에 쓰일 때만 |
| `LOW_TEXT`, `IMG×n` | 질문이 그 페이지의 그림/도표에 달려 있을 때만 렌더 |
렌더는 기본 110dpi, 작은 글씨일 때만 `--dpi 150`. 한 번에 꼭 필요한 페이지만.
별도 OCR API·외부 변환 서비스는 사용자가 요청할 때만 쓴다.

## 4. 분석 규칙
- 모든 사실 주장에 근거 페이지 `(p.N)`을 단다. 확인 못 한 페이지 번호는 만들지 않는다.
- 숫자 비교(단가·정산)는 텍스트 재해석보다 표 원값으로 계산하고, 키(SKU·옵션·통화·세금·단위)를 먼저 맞춘다. 문서에 없는 값은 `확인 필요`로 남긴다.
- 계약·세무·정책 문서는 적용일·대상·예외·각주를 별도 항목으로 확인한다.
- 시각 확인한 페이지와 텍스트만 본 페이지를 결과 끝에 구분해 적는다.
- 토큰 절감 수치를 추정해 말하지 않는다. 파일 크기·글자 수는 토큰 수가 아니다. 측정이 필요하면 `messages.count_tokens`로 동일 조건 비교를 제안만 한다.

## 5. 결과 저장
- 사용자가 다시 볼 결과는 `<이름>.analysis.md`(또는 요청 형식)로 저장하고, 상단에 원본 경로·sha16·분석일·시각 확인 페이지를 기록.
- 검수를 마친 캐시는 `meta.json`의 `review`를 `검수완료(날짜, 확인 페이지)`로 갱신.

## 6. 문제 해결
- 암호 PDF: 해제본을 요청. 손상 PDF: 오류 메시지 전달 후 다음 파일 진행.
- Drive 파일이 '온라인 전용'이라 열리지 않으면 사용자에게 오프라인 사용 설정 또는 1회 열기를 요청.
- 한 글자씩 띄어진 제목은 스크립트가 4음절 이상만 붙인다. 검색이 안 맞으면 띄어쓴 형태로도 grep.
- DOCX/PPTX/XLSX는 이 스킬 범위 밖: 필요 시 MarkItDown(`markitdown[docx,pptx,xlsx]`)으로 변환해 같은 캐시 규칙(`<sha16>/full.md`)을 따른다.
