# 자기소개서 작성·첨삭 가이드

## 목적

채용 담당자가 빠르게 이해할 수 있고, 사용자가 면접에서 그대로 설명할 수 있는 자기소개서를 만든다.

## 작성 원칙

1. 첫 문장에서 질문에 대한 답을 제시한다.
2. 한 문항에는 하나의 핵심 메시지를 둔다.
3. 경험은 상황 설명보다 사용자의 판단과 행동을 중심으로 쓴다.
4. 기술 이름을 나열하지 말고, 어떤 문제를 해결하기 위해 왜 사용했는지 설명한다.
5. 수치와 성과는 확인된 것만 사용한다.
6. `혁신적인`, `글로벌`, `끊임없이 성장하는 인재` 같은 상투어를 피한다.
7. 기업 칭찬으로 끝내지 말고 직무 과제와 기여 가능성을 연결한다.
8. 글자 수는 공백 포함 기준을 확인하고 제한에 맞춘다.

## 경험 구조

- 결론: 이 경험이 보여주는 역량
- 문제: 해결해야 했던 구체적인 상황
- 역할: 내가 책임진 범위
- 판단: 여러 선택지 중 해당 방식을 택한 이유
- 행동: 실제 수행 내용
- 결과: 확인 가능한 변화와 성과
- 연결: 지원 직무에서 어떻게 활용할지

## 첨삭 방식

초안을 받으면 먼저 다음을 냉정하게 진단한다.

- 질문에 직접 답하지 않는 문장
- 다른 지원자도 쓸 수 있는 추상적인 표현
- 같은 의미의 반복
- 역할과 팀 성과가 섞인 부분
- 면접에서 근거를 설명하기 어려운 주장
- 기업·직무 연결이 약한 부분

그다음 `문제점 → 수정 방향 → 수정본` 순서로 제시한다. 원문의 말투와 사실을 최대한 유지한다.

## 실행 명령 예시

> 공고, 문항, 내 초안을 첨부했어. 이 가이드에 따라 채용 담당자 관점에서 냉정하게 평가한 뒤 수정해줘. 글자 수는 공백 포함 800자 이내야.
