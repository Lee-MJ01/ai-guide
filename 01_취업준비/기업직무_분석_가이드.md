# 기업·직무 분석 가이드

## 목적

기업 소개를 나열하는 데서 끝내지 않고, 자기소개서와 면접에서 바로 사용할 수 있는 근거 중심의 분석 자료를 만든다.

## 조사 원칙

- 회사 공식 홈페이지, 채용공고, 사업보고서·공시, 공식 보도자료를 우선한다.
- 현직자 인터뷰와 기술 자료는 보조 근거로 사용한다.
- 최신성과 출처를 확인하고 각 핵심 주장에 링크를 남긴다.
- 공고 주체, 실제 근무 법인, 모집 직무의 소속이 다를 수 있으므로 명칭을 먼저 확정한다.
- 공식 사실, 외부 평가, 합리적 추론을 구분한다.

## 조사 항목

1. 기업 개요와 핵심 사업
2. 최근 전략·실적·사업 변화
3. IT·디지털·AI·데이터 관련 투자와 과제
4. 모집 직무의 실제 업무와 요구 역량
5. 사용 기술 또는 예상 기술 환경
6. 경쟁사·업계와 비교한 특징
7. 조직이 해결해야 할 문제와 지원자가 기여할 수 있는 지점
8. 사용자 경험과의 연결
9. 자기소개서 문항별 활용 소재
10. 예상 면접 질문·꼬리질문·반론

## 경험 연결 방식

경험은 `문제 → 내 역할 → 판단 → 행동 → 검증 → 한계/범위`의 6줄 카드로 정리한다. 사용자 배경 문서(`[Drive]/_개인/사용자_배경.md`)의 주요 경험 중 직무와 직접 연결되는 것만 선택한다.

## 최종 Markdown 구조

1. 한 페이지 핵심 요약
2. 기업·산업 분석
3. 직무 분석
4. 채용공고 요구사항 매핑표
5. 사용자 경험 연결표
6. 자기소개서 문항별 전략
7. 면접 질문과 답변 근거
8. 리스크·부족한 점·추가 확인 사항
9. 출처 목록

## 실행 명령 예시

> 첨부한 공고의 기업과 직무를 이 가이드에 따라 조사해줘. 자기소개서와 면접에 활용할 수 있는 Markdown 파일로 만들고, 내 경험과 연결할 때는 근거 없는 내용을 추가하지 마.
