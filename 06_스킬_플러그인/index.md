# 06_스킬_플러그인 · 인덱스

> 요약: 내가 만든 스킬, 남이 만든 스킬·플러그인의 목록·설치법·PC별 설치 현황. "이 작업에 쓸 스킬 있어?"의 답을 여기서 찾는다. | 갱신: 2026-11-20

## AI 사용 순서

1. `스킬_플러그인_레지스트리.md`에서 작업 키워드로 맞는 항목을 찾는다.
2. 지금 PC 이름(`hostname`)으로 `컴퓨터별_설치현황.md`를 보고, 설치돼 있으면 바로 쓴다.
3. 기록이 없거나 낡았으면 실제로 확인한다(`claude plugin list`, `~/.claude/skills/`). 없으면 레지스트리의 설치 명령을 사용자에게 보여 주고 승인 후 설치 → 현황 파일 갱신.

| 문서·폴더 | 언제 연다 |
| --- | --- |
| `스킬_플러그인_레지스트리.md` | 작업에 맞는 스킬·플러그인 찾기, 설치 명령 확인 (항상 여기부터) |
| `컴퓨터별_설치현황.md` | 이 PC에 무엇이 깔려 있는지 확인·기록 |
| `새_PC_세팅_체크리스트.md` | 새 PC나 포맷 후 한 번에 세팅 |
| `외부_추천_플러그인_25선.md` | 남이 추천한 GitHub 스킬·플러그인 25개 (설치 전 검토용) |
| `한국어_휴머나이저_korean-skills.md` | AI가 쓴 한국어 티 지우기 스킬 (릴스 정리) |
| `plugins/my-skills/` (저장소 루트) | 내가 만든 스킬 6종 원문. 고칠 때는 `00_공통기준/저장소_운영_규칙.md` 6장 |
