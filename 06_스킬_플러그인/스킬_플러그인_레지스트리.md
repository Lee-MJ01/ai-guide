# 스킬·플러그인 레지스트리

> 요약: 쓸 수 있는 스킬·플러그인 전체 목록. 종류별로 "어디서 동작하는지"와 "설치 방법"이 다르다. | 키워드: 스킬, 플러그인, 설치, marketplace, npx skills | 갱신: 2026-11-20

## 종류 먼저 이해하기 (어디서든 쓰이게 하는 방법이 다름)

| 종류 | 어디서 동작 | 다른 PC에서 쓰려면 |
| --- | --- | --- |
| **A. claude.ai 계정 스킬·플러그인** (내가 Claude에서 저장한 것) | Claude 앱(웹·데스크톱·모바일) + 같은 계정으로 로그인한 Claude Code (`Synced from claude.ai`로 자동 로드 확인됨) | **할 일 없음.** 로그인만 하면 따라온다 |
| **B. Claude Code 마켓플레이스 플러그인** (GitHub 저장소) | 설치한 PC의 Claude Code만 | PC마다 설치 명령 2줄 실행 |
| **C. npx/gh로 설치하는 스킬** (`~/.claude/skills/`) | 설치한 PC의 Claude Code만 | PC마다 설치. 또는 A로 올려 두면 계정 동기화 |
| **D. 커넥터** (Google Drive, Notion, Figma 등) | 계정 단위 | claude.ai 설정 → 커넥터에서 한 번 연결 |

> 원칙: 자주 쓰는 남의 스킬은 B·C로 PC마다 깔기보다 **A(계정 스킬)로 올려 두면** 모든 기기에서 따라온다. 단, 훅(hooks)·스크립트·MCP 서버가 필요한 플러그인(ECC, duel-chat 등)은 PC 설치가 필요하다.
