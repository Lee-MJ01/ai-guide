# AI 브라우저 업무 자동화 — 로그인된 화면을 사람처럼 조작하는 에이전트

> **주제 분류**: AI 에이전트 / 브라우저 자동화

---

## 1. 한 줄 요약

API 연동이나 키 설정 없이, **이미 로그인해 둔 브라우저 화면에 들어가 사람처럼 클릭**하는 AI 브라우저. 결제·발행 등 되돌릴 수 없는 마지막 버튼 **직전에 멈춰서 사용자에게 물어본다.**

---

## 2. 핵심 설계 포인트

| 특징 | 내용 |
|---|---|
| 연동 방식 | **API·OAuth 설정 없음**. 기존 로그인 세션 위에서 직접 조작 |
| 조작 방식 | 화면 요소를 식별해 사람처럼 타이핑·클릭 |
| 안전장치 | **결제 직전 / 발행 직전 / 최종 제출 직전에 정지** → 마지막 버튼은 사용자가 누름 |
| 예외 처리 | 자동 서식 깨짐 등 오류 인지 시 스스로 지우고 재작성 |
| 플랫폼 | 기존 버전 + **윈도우 버전 출시** |

> 💡 "기능이 아니라 **멈추는 지점**이 인상적" — 이 정지 구간이 있어야 계정을 맡길 수 있다는 것이 원문의 핵심 논지.

---

## 3. 검증된 활용 사례 5가지

### ① 네이버 블로그 자동 포스팅

**요청**: 주제만 전달
**동작**: 네이버 블로그 스마트에디터 접속 → 제목·본문 초안 작성 → 카테고리·태그 정리 → **발행 직전 정지**

에이전트 실행 로그 예시:
```text
Read full6.png
슬라이드 5장 내용 다 읽었어요. 이제 초안 쓸게요.
Used Draft Preview skill
초안 다 썼어요. 이제 네이버 블로그 에디터에 올릴게요.
Browsed the web, ran actions
Typing the title
Thinking
숫자 목록이 자동서식으로 깨져서 본문을 다시 쓸게요.   ← 예외 처리
Clearing the body
Retyping the body (part 1)
```

> 주목: 자동 서식 오류를 **스스로 감지하고 본문을 지운 뒤 재작성**하는 복구 동작.

---

### ② 인스타그램 언팔로우 확인

**동작**: 팔로워와 팔로잉 목록을 비교 → 내가 팔로우하지만 나를 팔로우하지 않는 계정 목록화
**정지 지점**: 언팔로우 실행은 **사용자가 직접 결정**

---

### ③ 홈택스 서류 탐색·다운로드

**요청 예시**: "상속세 전자신고 파일설명서 찾아줘"
**동작**: `hometax.go.kr` 통합검색 → 자료실 게시물 진입 → 전체 다운로드
**결과**: `상속세전자신고파일설명서(2026년2월).pdf` 외 2건 저장
**정지 지점**: 최종 제출 전 내용 확인 단계

> 메뉴 위치를 몰라도 목적지까지 직접 이동해 절차를 정리해 줌.

---

### ④ 코레일 매진 좌석 감시·예약

**요청**:
```text
3초에 한번씩 새로고침하고 2시 15분 일반석 좌석이 나오면 알림해줘.
```

**동작**:
- 검색 조건: 서울 ⇄ 부산 / 2026-09-19(토) 14:00 / 1명 / 일반석 / 직통
- 대상: `KTX 145` (14:15 → 16:45, 현재 **매진**)
- 3초 간격 새로고침 루프 실행, `Working for 1m 3s` 식으로 감시 시간 누적
- 새로고침으로 페이지 참조가 무효화되면 **감시 동작을 페이지에 다시 거는** 자가 복구

**정지 지점**: **결제 직전**

---

### ⑤ Gmail 스팸 일괄 정리

**요청**:
```text
받은 편지함에서 스팸 의심 되는 이메일들을 찾아서 하나씩 들어가보고 삭제처리해줘.
직접 브라우저로 들어가서 확인해줘.
```

**동작**: Gmail 검색 쿼리를 단계적으로 정교화하며 후보 선별
```text
in:inbox "ReefSpins"
in:inbox ("free spins" "free reward" winner "account blocked" ...)
in:inbox ("account blocked" "renew your subscription" ...)
```
- 각 메일을 **실제로 열어 발신자·본문 확인** 후 휴지통 이동
- 상태 메시지: `Refining search strategy`, `Considering spam messages`
- 검색 결과 갱신으로 화면 참조가 무효화되면 재검색 후 이어서 처리

**정지 지점**: 구독 해지 페이지까지 이동하되 **최종 확인은 사용자**

## 4. 공통 패턴 — "멈추는 지점" 정리

| 작업 | 자동으로 하는 것 | 사용자가 누르는 것 |
|---|---|---|
| 블로그 포스팅 | 제목·본문·태그 작성 | **발행** |
| 언팔 정리 | 비교·목록화 | **언팔로우** |
| 홈택스 | 검색·이동·다운로드 | **최종 제출** |
| 기차 예매 | 감시·좌석 선택·예약 화면 진입 | **결제** |
| 메일 정리 | 검색·분류·휴지통 이동 | **구독 해지 확정** |

---

## 5. 검증 유의사항

- 영상에 표시된 모델명(`Opus 5 High`, `GPT-5.0 Luna Medium` 등)은 영상 내 UI 표기로, 실제 상용 모델명과 일치하는지는 화면만으로 확인 불가
- 백엔드 구현 방식(API 제어 / RPA 방식 / 브라우저 확장)은 영상에 노출되지 않음
- 일부 사례(언팔 확인 등)는 결과 화면 없이 기능 설명만 제시됨
