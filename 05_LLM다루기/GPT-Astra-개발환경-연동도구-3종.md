## 1. 핵심 전제

무작정 프롬프트만 던지는 것보다 **Astra가 제대로 일할 수 있는 환경을 먼저 만드는 것**이 중요. 오픈소스 3가지를 붙이면 문서 최신성·사전 조사·작업 연결성 문제를 각각 해결한다.

> ⚠️ 영상의 "성능 5배"는 시각적 연출용 상징 수치. 프로젝트 종류에 따라 개선 폭은 다름.

## 3. ① Context7 — 최신 문서 실시간 공급

**역할**: 코딩 에이전트 옆에서 **최신 개발 문서를 계속 펼쳐주는 문서 담당**.

**동작 흐름**
1. 에이전트가 특정 라이브러리(예: `Next.js 14`) 관련 질의 처리 시작
2. Context7이 우측에서 **최신 공식 문서를 즉시 조회**해 보조
3. 구버전 문법 사용 시 "그 코드는 옛날 버전이야" 하고 **적발**
4. **최신 문법으로 교정** (예: `middleware.ts` 구버전 패턴 차단)

**효과**: 몇 년 전 문법으로 코드를 짜는 경우가 급감 → 버전 불일치로 인한 오류 감소.

---

## 4. ② GPT Researcher — 출처 달린 사전 조사

**역할**: **코드보다 조사가 먼저**. 코딩 전에 시장·경쟁사를 대신 조사.

**동작 흐름**
1. 공식 사이트, 가격표, 리뷰, 뉴스 등 **여러 사이트(영상 기준 약 20곳) 순회**
2. 자료 수집 및 정리
3. **출처가 포함된 보고서** 자동 작성

**효과**: 근거 없는 가정으로 설계를 시작하는 것을 방지. 보고서에 출처가 달려 있어 사후 검증 가능.

---

## 5. ③ LangGraph — 작업 순서 연결 + 체크포인트 재개

> 영상에서 **가장 중요**하다고 강조한 도구.

**역할**: 복잡하게 엉킨 AI 작업 뭉치를 **순서대로 연결**하고, 중단돼도 이어서 실행.

**동작 흐름**
1. 엉킨 작업 노드들을 한 줄 프로세스로 정렬
   ```text
   조사 → 분석 → 검토 → 실행
   ```
2. 작업 중 중단 발생 (예: 진행률 79%에서 정지)
3. **체크포인트에서 재개** → 끊긴 지점부터 다시 100%까지 진행
   - `resuming from exactly where they left off`

**효과**: 장시간·다단계 에이전트 작업이 중간 실패로 통째로 날아가지 않음.

## 6. 적용 순서 제안

```text
1. Context7 설치      → 문서 최신성 확보 (즉시 효과, 설정 부담 낮음)
2. GPT Researcher 도입 → 설계 전 조사 루틴화
3. LangGraph 구성      → 다단계 워크플로우 정의 + 체크포인트 설정
```
