## 1. 무엇을 해결하나

- 클로드 코드 답변 기다리느라 퇴근이 늦어짐
- 외출 중에 PC에서 하던 작업을 이어가고 싶음

→ **노트북 없이 스마트폰으로** 기존 대화 기록을 그대로 확인하고 추가 지시 가능.

---

## 2. ① 클로드 코드 원격 연동 — 명령어 한 줄

### 절차

1. 스마트폰에 **Claude 앱** 설치
2. 작업 중인 **PC에서 터미널** 열기
3. 아래 명령어 중 하나 입력

```bash
/remote-control
```

또는

```bash
claude rc
```

4. 실행하면 QR / 접속 링크 안내가 표시됨
   - 터미널 출력 예: `Continue coding in the Cla...`, `...e.ai/code?environment=`, `space to show QR code.`
5. 폰으로 접속 → 연결 완료

### 모바일에서 확인하기

Claude 앱 접속 → **`코드` 탭** → 세션 목록 확인

```text
기기
  💻 -MacBookPro

세션 전체 ∨
  ● -macbookpro-local-silly-feige...     💻 연결됨 · -MacBookPro        1분
  ↻ 자동화 게시물 생성                    💻 연결됨 · <repo>            작업 중 · 2분
  ● Notion 카드뉴스 워크플로우             💻 연결됨                     27분
  ● 와이어프레임 수정 가능성               💻 연결됨 · <repo>            2시간
  ● cardnews_app_ 배포용 Flask 서버       💻 연결됨                     3시간
```

- PC 세션 기록이 **그대로 연동**됨
- 이전 대화 확인 + 실시간 추가 지시 가능
- 세션별로 연결된 저장소 경로와 마지막 활동 시간 표시

---

## 3. ② ChatGPT(Codex) 원격 조종 — QR 코드 한 번

### 절차

1. **ChatGPT 데스크톱 앱 + 모바일 앱** 모두 설치
2. PC 앱에서:
   ```text
   설정 → 연결 (원격 제어) → 추가
   ```
3. QR 코드가 뜨면 **폰으로 스캔**
4. 폰에 승인 팝업 표시 → 승인
   - `Allow this phone to access Codex on your computer?`
   - `이 컴퓨터를 원격으로 제어하도록 기기에서 승인하세요`
5. 연결 완료

---

## 4. ⚠️ 필수 주의사항

> **PC가 꺼지면 원격 제어도 중단됩니다.**

외출 전 체크리스트:

- [ ] PC 전원 켜두기 (서버 역할)
- [ ] **절전 / 잠자기 모드 해제** 설정
  - macOS: 시스템 설정 → 배터리·디스플레이에서 잠자기 방지
- [ ] 필요한 세션이 실행 중인지 확인

## 5. 두 방식 비교

| | 클로드 코드 | ChatGPT Codex |
|---|---|---|
| 연결 방식 | 터미널 명령어 1줄 | PC 앱 설정 → QR 스캔 |

| 세션 확인 | 앱 내 `코드` 탭 | 원격 제어 연결 목록 |
